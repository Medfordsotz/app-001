# app-001
El proyecto “Sistema de Envíos Garantizados S.A.” es una aplicación desarrollada en C++ bajo el modelo MVC, que permite gestionar el registro, control y seguimiento de envíos. Su objetivo es optimizar la organización de paquetes y mensajes, ofreciendo una interfaz sencilla, rápida y funcional para los usuarios.
🚀 Características Principales

📋 Registro y administración de usuarios, clientes y envíos.

💬 Envío y recepción de mensajes asociados a solicitudes.

⚙️ Interfaz de consola intuitiva y dinámica.

🧠 Estructura modular con carpetas controllers, models, views y utils.

💾 Almacenamiento en archivos locales, sin necesidad de base de datos externa.

🧱 Código limpio, estructurado y fácil de mantener.

🏗️ Estructura del Proyecto
📁 app-001/
 ├── controllers/      # Controladores del sistema (usuarios, mensajes, solicitudes)
 ├── models/           # Modelos con persistencia de datos en archivos
 ├── views/            # Interfaz de usuario (menús, pantallas y mensajes)
 ├── utils/            # Funciones auxiliares (UI, validaciones, limpieza)
 ├── main.cpp          # Punto de inicio del programa
 └── README.md         # Documento de información del proyecto

⚙️ Requisitos del Sistema

🖥️ Compilador: g++ (C++20 o superior)

💡 Sistema Operativo: Windows, Linux o macOS

🧰 Editor recomendado: Visual Studio Code, Code::Blocks o CLion

▶️ Ejecución del Programa

Compila el proyecto:

g++ -std=c++20 -O0 -g -Iinclude src/*.cpp -o bin/app.exe


Ejecuta el programa:

./bin/app.exe
